# Maestría en Inteligencia Artificial — UNI

Trabajos de cursos de la **Maestría en Inteligencia Artificial** de la Universidad Nacional de Ingeniería (Escuela de Posgrado), actualmente **en curso**. Son entregables grupales; los integrantes de cada grupo figuran en el README de cada trabajo.

## Contenido

| Curso | Trabajo | De qué trata | Stack |
|---|---|---|---|
| Big Data | [AgroSmart Andino](Big_data/trabajo_final/agrosmart_andino) | Sistema de monitoreo y recomendación de riego para cultivos de papa nativa en Huangascar (Yauyos): adquisición de datos climáticos de NASA POWER y datos IoT simulados, validación de datasets, capas de datos hasta *gold*, carga en Cassandra y dashboard | Python · PySpark · Cassandra · Streamlit · laboratorio de AWS Academy (S3, EMR) |
| Redes Neuronales y Aprendizaje Profundo | [Clasificación de llantas dañadas](Redes%20Neuronales%20y%20Aprendizaje%20Profundo/Ejercicio_1_RN_AP/Examen_Parcial/Parcial_Parte_1) | Clasificación binaria de imágenes (`normal` vs `cracked`) comparando una CNN entrenada desde cero con ResNet-50, con estudios de ablación configurables | PyTorch · CNN · ResNet-50 |

## Nota

Los identificadores de infraestructura que aparecen en el proyecto de Big Data corresponden a un laboratorio temporal de AWS Academy que ya no existe. El repositorio no contiene credenciales; las variables se configuran a partir de `.env.example`.
